{{- /* Markdown link render hook. - Internal links (a single leading /) are existence-gated at render time for EVERY section, not a fixed allow-list: if site.GetPage resolves the target it renders a language-relative ; if not, the link text is kept as plain text with no href. So a prose link can never dead-link, and it lights up on its own once that page is built (never stale). This lets the assembler over-link every potentially-linkable entity and rely on the site to strip the ones whose page does not exist. NB: a render hook only sees markdown links [text](/path); raw in content bypasses it entirely, so the assembler must emit markdown links only, with bare (non-language-prefixed) paths. - Only the FIRST mention of a target in a page links; later mentions of the same page render as plain text. The assembler links every mention, which was invisible while most targets had no page yet - as the entity pages land, a page that quietly held ten stripped mentions turns into ten live links to the same place. First-mention-only is the ordinary editorial rule and keeps an article readable rather than blue. - Link text that stands in for an unknown person - "[interviewer 2]", "[redacted]", "Speaker 3" - never links, whether or not a page of that name exists, and keeps its brackets. See partials/is-role-description.html. - External links, workbench deep-links (http...), protocol-relative (//), anchors (#...) and mailto pass through untouched. */ -}} {{- $dest := .Destination -}} {{- $roleDescription := partial "is-role-description.html" .Text -}} {{- $internal := and (strings.HasPrefix $dest "/") (not (strings.HasPrefix $dest "//")) -}} {{- if $roleDescription -}} {{ .Text | safeHTML }} {{- else if $internal -}} {{- $lookup := index (split $dest "#") 0 -}} {{- $lookup = index (split $lookup "?") 0 -}} {{- $seen := or (.Page.Store.Get "linkedTargets") slice -}} {{- if and (site.GetPage $lookup) (not (in $seen $lookup)) -}} {{- $_ := .Page.Store.Set "linkedTargets" ($seen | append $lookup) -}} {{ .Text | safeHTML }} {{- else -}} {{ .Text | safeHTML }} {{- end -}} {{- else -}} {{ .Text | safeHTML }} {{- end -}}
