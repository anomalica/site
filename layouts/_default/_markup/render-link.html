{{- /* Markdown link render hook. - Internal links (a single leading /) are existence-gated at render time for EVERY section, not a fixed allow-list: if site.GetPage resolves the target it renders a language-relative ; if not, the link text is kept as plain text with no href. So a prose link can never dead-link, and it lights up on its own once that page is built (never stale). This lets the assembler over-link every potentially-linkable entity and rely on the site to strip the ones whose page does not exist. NB: a render hook only sees markdown links [text](/path); raw in content bypasses it entirely, so the assembler must emit markdown links only, with bare (non-language-prefixed) paths. - Link text wrapped in square brackets is a role description, not a name - "[interviewer 2]", "[audience member]". It identifies who someone was in one recording, is scoped to that record, and names no person, so it must never become a link even if a node page of that name exists. The brackets are the reader's signal and stay in the text. A bare "Speaker 3" is the same thing in the older unbracketed notation - a diarisation id, never a person - and is held to the same rule. - External links, workbench deep-links (http...), protocol-relative (//), anchors (#...) and mailto pass through untouched. */ -}} {{- $dest := .Destination -}} {{- $text := printf "%v" .Text -}} {{- $bracketed := and (strings.HasPrefix $text "[") (strings.HasSuffix $text "]") -}} {{- $diarisationId := findRE `(?i)^\[?\s*speaker\s+\d+\s*\]?$` $text 1 -}} {{- $roleDescription := or $bracketed $diarisationId -}} {{- $internal := and (strings.HasPrefix $dest "/") (not (strings.HasPrefix $dest "//")) -}} {{- if $roleDescription -}} {{ .Text | safeHTML }} {{- else if $internal -}} {{- $lookup := index (split $dest "#") 0 -}} {{- $lookup = index (split $lookup "?") 0 -}} {{- if site.GetPage $lookup -}} {{ .Text | safeHTML }} {{- else -}} {{ .Text | safeHTML }} {{- end -}} {{- else -}} {{ .Text | safeHTML }} {{- end -}}
