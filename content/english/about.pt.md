Anomalica é uma plataforma de referência estruturada para fenómenos anómalos. Cada afirmação factual no site está vinculada a um documento fonte específico, e a força das evidências é calculada algoritmicamente, não editorialmente.

## O que isto é

Uma enciclopédia construída a partir de fontes primárias. Documentos são ingeridos, afirmações são extraídas e artigos são gerados a partir de um grafo de conhecimento. O processo é transparente e auditável.

## O que isto não é

Isto não é um site de opinião, um agregador de notícias nem um fórum comunitário. O conteúdo não é editorializado. As evidências são avaliadas por algoritmo, não por julgamento editorial. A plataforma não toma posição sobre a natureza ou origem dos fenómenos que documenta.

## Independência

Anomalica não está alinhada com qualquer interesse nacional, agência governamental ou patrocinador corporativo. É autofinanciada, de código aberto e concebida para resistir a pressões institucionais. A arquitectura de alojamento é construída para resiliência através de jurisdições.

## Código aberto

Todo o código é licenciado sob MIT. Todo o conteúdo é de domínio público sob CC0. O grafo de conhecimento completo está disponível para transferência como ficheiro SQLite.
